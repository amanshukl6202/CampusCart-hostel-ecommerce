# 🛒 CampusCart — Hostel E-Commerce Store

A fully functional single-page e-commerce website built specifically for hostel students. No frameworks, no build tools — pure HTML, CSS & JavaScript.

## 🔗 Live Demo
[View Live →](https://TERA_USERNAME.github.io/campuscart-hostel-ecommerce)

## ✨ Features
- 🏠 Landing page with hero section & category navigation
- 🛍️ 42+ hostel-relevant products across 7 categories
- 🔍 Search, filter by category & sort (price/rating)
- 🛒 Cart with quantity controls & order summary
- 🔐 User auth — Sign In / Register (localStorage)
- 💳 3-step checkout — Delivery → Payment → Confirm
- 🎟️ Coupon system (try: `HOSTEL10`)
- 📱 Fully responsive (mobile friendly)
- 🔔 Toast notifications on every action
